NodeHerder · design exploration · ring 2

Daily surfaces, one system

Ring 2 aligns the surfaces people use every day: Home, Devices, a device, the redesigned Overview, Integrations and Panel mode. It starts with a pattern sheet, because the goal is not six new pages — it is one vocabulary for freshness, actions, rows and states. All frames reuse the Ring 1 tokens; nothing here introduces a new visual language. Reviewed against ui-ux-pro-max guidance for hierarchy, touch targets, contrast, focus and confirmation.

Recommendation: ring 0 patterns first, then devices + overview No production code changed

1 · Status and freshness vocabulary

Fresh● Online · 18 sDevices, Home, device header · normal
Quiet◷ Quiet · 4 hHome, Devices, Overview · amber hint, controls stay enabled
Stale◷ Stale · 1 dDevices, device header · amber-red, “last known” labels
Offline⚠ OfflineAll surfaces · values last known, controls paused
Disabled⊘ DisabledDevices, integrations · hub ignores updates
Unknown? UnknownBefore first report or after removal
Pending↻ Refreshing…Integration rows, device commands · never a spinner alone
Failed⚠ FailedAutomations, integrations · links to the reason

Rule: availability and silence are separate facts. A quiet device is still “Online” for automation routing; the chip adds the silence. Never encode both in one colour.

fresh · within intervalquiet · 3× (min 15 min)stale · 12× (min 6 h) or socket down

1 · Home consistency pass

control surface

Home is the control surface; Overview is the status surface. Ring 2 adds one thing to Home: a compact status strip that links to the calm Overview, plus room-level health. No new cards, no duplicated network tables, no second attention list.

Design rule: Home answers “turn this on / what is this room doing?”. Overview answers “is anything wrong, and what first?”. The same status vocabulary, different jobs.

Desktop — status strip, then rooms

One strip between the header and the rooms. Room headings carry a health count only when something is wrong; otherwise they stay quiet.

4 · Overview, redesigned

too noisy

The current Overview stacks four stat cards, a connection group, three attention groups, an activity feed and a network table — nine competing blocks, most repeating each other. The fix is hierarchy, not deletion: one verdict, the top three actions, one compact health line, and the rest below the fold or behind a link.

A

“Calm” — one verdict, three actions, one line of facts

Recommended. A single status card states the verdict in plain language; “Start here” lists the three highest-value actions; everything else becomes one links-only health line. No network table, no four-card stat row, no duplicate attention groups. All-clear state: “Everything looks fine. 42 devices reporting, 24 automations on.” — no empty-card graveyard.

6 · Panel mode

wall tablet · 2 m glance

Panel mode is not a responsive page — it is a different device. The design brief: readable at two metres, tappable with a thumb, no navigation chrome, honest when the hub is down, and calm at night. It keeps the same data and commands; only scale, density and priority change.

Current: full-screen room pager, climate dial, tile buttons, status page with four dials, dock. Changes: larger targets, one accent light, night simplification, offline banner that never blocks controls silently.

Clock and weather are glanceable, not dominant. The climate dial is the only large instrument; everything else is a big target with state and value.

7 · Decisions to confirm

before spec

Ring 2 scope

Home, Devices, Device detail, Overview, Integrations and Panel mode. Editors, Assistant and Login stay out. Home only gets the status strip and room health, not a rebuild.

Overview direction

A “Calm” is recommended: one verdict, three actions, one health line, three events. B “Domain board” is the operator alternative. Pick one; do not ship both.

Home ↔ Overview boundary

Home is control, Overview is status. The “while you were away” digest moves to Overview. Home keeps a single status strip linking to it.

Panel mode rules

Night mode drops to four essentials plus a large clock; offline shows one banner and marks controls “Paused”. Confirm how night is triggered (schedule vs ambient light) and which four controls are configurable.

Device list truth

Add both a quiet filter and a freshness column, not only the combined status chip. Keep the table on desktop; card rows on mobile.

Integrations refresh

Per-row refresh plus one board-level “Refresh all”. No refresh-on-open; it invites rate limits. Continuous integrations show no refresh button.

Interaction contract

Ring 0 extraction during Ring 1: visible focus, 44 px primary targets, 8 px gaps, colour never alone, specific destructive confirmation, no hover-only affordances.

Panel scope

Panel is a landscape wall surface, not a responsive phone layout. It keeps its own density and font scale; it does not need to match desktop card sizes.
