Sample 6 — bottom navigation and thumb-first history

Below 960 px the app hides the sidebar behind a hamburger. This sample tests a five-item bottom bar (the token --nh-bottom-nav-h: 3.75rem already exists, unused).

  • Bottom tabs keep the five destinations a thumb can reach; “More” holds console, assistant and settings.
  • Scrollable chip rows for range and entity instead of wrapping selects.
  • Pull to refresh matches the manual refresh button, with a visible gesture affordance.
  • Safe areas: the nav sits above env(safe-area-inset-bottom), which only works with viewport-fit=cover (set on this page, missing in the app).

Decision to make: five tabs (Home, Devices, Automations, History, More) vs four plus a menu.
