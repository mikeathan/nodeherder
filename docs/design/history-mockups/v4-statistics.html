Sample 4 — History vs Statistics

Home Assistant separates History (samples) from Statistics (aggregates for long ranges). NodeHerder already computes avg, min, max and count server-side but never asks for them, so a 30-day view is limited to 10 000 raw points.

  • Statistics shows daily aggregates as bars — cheap to read and cheap to query.
  • Table gives min / average / max / samples per day, with the same numbers as the chart.
  • Export CSV uses the same range, and the file is generated from the loaded data.
  • Raw History stays available for zoomed inspection of a single day.

Decision to make: one control with a mode switch (shown) vs a separate Statistics page.
