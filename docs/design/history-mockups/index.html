History, charts and mobile — design samples

Six static prototypes for the history/chart rework (spec 007 follow-up, T209–T212) and the mobile shell. Synthetic data, real tokens, no build step and no application code. Open any sample, then use the top bar to switch theme (Fleece / Daylight) and mode (dark / light).

temperature humidity illuminance battery / comfort Chart interactions: hover for a value, drag a region to zoom, double-click to reset, click a legend entry to toggle a series.

1 · Discoverable history

Range and entity become visible controls; the chart gets the full width.

  • Range chips incl. Today / Yesterday
  • Entity chips with sensor colours
  • 360 px chart, readout, stats strip

Decide: chips vs select; history as a nav entry.

Open sample 1

2 · Multi-series and compare

More than one series at a time, with legend toggles and annotations.

  • Measured value + target setpoint
  • Previous-day ghost comparison
  • Comfort band and automation marker

Decide: second y-axis for mixed units, or same-unit only.

Open sample 2

3 · Zoom, layers, expand

The T211 “inspection / zoom / reset” control study.

  • − / + / Reset, drag-zoom, wheel, double-click
  • Expand to a 540 px overlay
  • Line / step / bars on the same data

Decide: add the zoom plugin (~8 kB) or rely on presets.

Open sample 3

4 · History vs statistics

Aggregated long ranges, using the aggregations the backend already has.

  • Daily bars for 7 / 30 days
  • Min / average / max / samples table
  • CSV export affordance

Decide: mode switch on one page vs separate Statistics page.

Open sample 4

5 · Mobile: sheet → full history

Two phone frames: the entity sheet and the full history it opens.

  • Compact 170 px preview with a primary “View full history”
  • 220 px full chart, chips, 2×2 stats
  • Safe-area aware actions

Decide: entry points (tile long-press, sheet button, nav).

Open sample 5

6 · Bottom navigation

Thumb-reachable tabs instead of the hamburger, with mobile history.

  • Five bottom tabs, safe-area padding
  • Scrollable chip rows, pull-to-refresh
  • Home tile that hints at the sheet

Decide: five tabs vs four plus a menu.
