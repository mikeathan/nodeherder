NodeHerder redesign — design samples

Five interactive, dependency-free prototypes for spec 007. All share the same mock household and screens, so you can compare look & feel directly. Every sample has a live Appearance panel (palette icon, top right): mode, palette, accent (incl. custom colour), density, corner radius, text size and retro effects. Switch designs from that panel and you stay on the same screen. Mix-and-match is fine — tell me e.g. “Mesh layout with the Studio controls”.

What to try in each sample

  • Home: tap a tile icon to switch — it shows Sending… until confirmed. The Garage → Hallway Shelly plug simulates a 5 s command timeout. “Edit dashboard” adds/renames/removes areas and tiles.
  • Automations → any automation: the new single-page When / If / Then editor. Remove a value or add an action to see inline validation, the live sentence summary, warnings, the JSON payload view and the unsaved-changes guard.
  • Device list: search, protocol (Zigbee / Wi-Fi·HTTP), power and status filters, sortable columns; Zigbee-only actions are disabled for HTTP devices.
  • Overview: Zigbee2MQTT-style counts and a live activity feed. Click the connection pill in the header to simulate reconnecting / offline.
  • Components: every building block and state (tiles, chips, dialogs, toasts, empty/error/loading, tokens, icons).
  • Keyboard: Alt+1…9 switches sections, Esc closes dialogs; all controls are focusable. Try a phone-width window too.
